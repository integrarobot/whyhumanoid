Why Humanoid? / Agents

For your software agents

Use the catalogue from your agents

Your agents can read Why Humanoid? the way you do: the free catalogue without any key, and complete Deployments and Components with your subscription. Same account, same access, no extra charge.

Before you start

  1. Free data needs nothing: the API, the MCP server and the command-line tool all work without a key, with public values.
  2. For complete Deployments and Components, subscribe (US$100 per year), then create an API key in the app, under Agent access. The key is shown once; keep it like a password.
  3. Revoke a key there at any time; it stops working at once. When the subscription ends, keys fall back to public values.
Fair use
60 requests a minute and 5,000 a day per key. Over the limit, requests get HTTP 429 with a Retry-After header; nothing is charged.
What agents can read
The published catalogue: every category, and with a subscription every field of Deployments and Components. Not accounts, orders, custom reports or internal tables.

HTTP API

JSON over HTTPS at https://whyhumanoid-premium.javier-198.workers.dev. Send the key as a Bearer token.

# Tables and what your access reads from each
curl https://whyhumanoid-premium.javier-198.workers.dev/v1/datasets

# Search across categories
curl "https://whyhumanoid-premium.javier-198.workers.dev/v1/search?q=pallet&category=deployments" -H "Authorization: Bearer YOUR_API_KEY"

# Rows of one table (every field with a subscription)
curl "https://whyhumanoid-premium.javier-198.workers.dev/v1/datasets/deployments?limit=25&offset=0" -H "Authorization: Bearer YOUR_API_KEY"

# Without a key: the public rows of Deployments
curl https://whyhumanoid-premium.javier-198.workers.dev/v1/datasets/deployments/preview

Published atlases (Datasets, Benchmarks, Reports, Integrators and the evolution charts) are public JSON files on this site, for example https://whyhumanoid.com/data/reports/atlas.json.

MCP server

A remote MCP server (Streamable HTTP) at https://whyhumanoid-premium.javier-198.workers.dev/mcp, with read-only tools: list_categories, search_catalogue, get_rows, get_atlas, get_relations and account_status. Add it to any client that supports remote MCP servers with a custom header, for example in a JSON configuration:

{
  "mcpServers": {
    "whyhumanoid": {
      "type": "http",
      "url": "https://whyhumanoid-premium.javier-198.workers.dev/mcp",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}

Leave out the header to use the public catalogue only. The exact place for this configuration depends on your client; check its documentation for "remote MCP server" or "HTTP transport".

Command-line tool

One JavaScript file with no dependencies (Node.js 18 or later). Read it before you run it: whyhumanoid.mjs.

curl -fsSLO https://whyhumanoid.com/agents/whyhumanoid.mjs
export WHYHUMANOID_API_KEY=YOUR_API_KEY   # optional: public data needs no key
node whyhumanoid.mjs categories
node whyhumanoid.mjs search pallet --category deployments
node whyhumanoid.mjs rows deployments --limit 5
node whyhumanoid.mjs atlas reports
node whyhumanoid.mjs account

Output is JSON. Run node whyhumanoid.mjs --help for every option.

Good to know

Records are claims as their sources state them, not verified facts; missing values stay missing. Custom company reports are ordered by people, in the app, not through these tools.
