Robotics and Physical AI Course - How to use AI Agents to analyze opportunities in robotics

We use Codex to analyze industrial conversion opportunities in robotics

By Javier Martín · First published in Spanish on 25 June 2026 · English translation dated 27 November 2026 · Original edition

So many humanoid robots are going to be sold in the future that it is almost certain many industries will be able to take the opportunity to retool and work in a sector with much higher growth than current ones.

That is why, in this class of the Robotics and Physical AI course, we use Codex to analyze the opportunities there may be for industrial companies to carry out that conversion and become suppliers of components for humanoid robots.

This is just one example of the thousands of cases that can be carried out applying AI Agents to robotics. In this case, what we did was first give the AI the context needed to analyze a company, then test it with a first company, and based on that analysis create a skill that we can later use with other companies.

Skills allow us to standardize a process so that the AI always carries it out the same way; in this way we can turn to that skill whenever we need it, just by mentioning its name in the chat.

Then what we did was create an automation based on that skill, which allows us to run that standardized process over time, for example in this case to do one company analysis a week.

Finally, once we have created the automation, we can move on to creating an HTML page so that the AI better understands the process to follow in this analysis work, and so that we can use the tool as reinforcement for the content the AI provides after the analysis.

In upcoming classes of the course we will keep learning how to use AI to learn and work in robotics, for example through CAD design of robot components, drawing up robotics deployment plans and a lot of things that are now much more within our reach thanks to Intelligent Agents.
