How to create your second digital brain about robotics

AI Agents are our best ally for working with robotics. You will take the robot out of the box and Codex will get it working.

By Javier Martín · First published in Spanish on 16 June 2026 · English translation dated 27 November 2026 · Original edition

We are starting a new recorded online course devoted to robotics and Physical AI, and to begin with, what we are going to do is learn to use AI agents, such as Codex and Claude, to help us with everything related to working with robots.

In this course, to start, we are going to learn to analyze robots and robotics research, and then get into using robot simulators, designing robots, creating deployment plans and anything else we can think of.

In this first video I show you how to create a second digital brain through the idea of the LLM Wiki published by Andrej Karpathy, which will help AI assist us by doing its work much more precisely and without errors.

This is the content you will be able to see in the video:

  1. Download the Codex or Claude app on your computer
  2. In Codex, create a project, name it robotics (or whatever you like) and open a new chat inside it
  3. In Claude, create a new chat
  4. Copy the text called LLM Wiki written by Andrej Karpathy
  5. Paste the LLM Wiki text into the chat
  6. In Codex, check that a folder has been created on your computer
  7. In Claude Code you have to select the folder in which you want the files to be generated
  8. Check that it has created the files Agents.md, Readme.md, Index.md, …
  9. Feed the Wiki (your second brain about robotics) with the following sources Integrarobot https://www.youtube.com/@Integrarobot
  1. Humanoid robot database
  2. Ask the AI some questions to check that it has internalized the knowledge from the sources
  3. Ask it to create a skill for evaluating robotics papers. Once it is created, give it a paper to analyze
  4. Tell it to upload the skill to your Github account

In the rest of the videos we will keep building our second digital brain about robotics through the following topics:

  1. Creating the 2nd Brain and a skill
  2. Creating HTML and automations
  3. Using Clade and visualizing with Obsidian
  4. Working with robot simulators
  5. Robotics designs with CAD
  6. Creating software applications
  7. Designing workflows
