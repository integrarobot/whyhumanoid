I'll teach you to use AI agents such as Codex and Claude Code

This is your chance to learn about AI Agents: a course in which you learn to use Codex and Claude Code and then apply them to robotics.

By Javier Martín · First published in Spanish on 17 June 2026 · English translation dated 27 November 2026 · Original edition

Image: Image

Is Integrarobot going to become an AI newsletter? No, but since I have been using Codex intensively I have realized that it is going to become the necessary hinge for robotics to take off.

Some time ago I wrote here about AI Agents, but back then I saw them as an example to follow for the development of VLAs, because of the need for an AI that is able not only to recognize images and text (or generate them) but also to take action.

But now the approach is different, because AI Agents don't need to occupy the robot's brain, since specific models are being developed for that, such as WAMs; rather, the point is to use them for developing robots.

The people at NVIDIA have just given us an example of what I'm describing, so you know what I mean. It is the ENPIRE project, where 8 Codex agents have been put in charge of a fleet of robots, with the simple goal of solving a task as fast as possible, keeping the robots busy but safe, and not wasting valuable compute.

The result is that AI agents such as Codex, Claude Code and Kimi Code can now be used to test robots 24/7 and thereby significantly improve progress in software development and robot training, without having to wait for an engineer to be available to run these tests.

And what I want to tell you here today is that ENPIRE is just the tip of the iceberg, because I'm going to give you the answer to a very common question: how is it possible that new humanoid robots keep coming out almost every day? For example, yesterday ENO was presented by Genesis, which until now had devoted itself to making AI software for robots. So the reason is clear: it is the use developers are making of AI to create robots.

So this is what I want to teach you in the course I have already started recording, of which a first class is available: how to create your second digital brain about robotics, using Andrej Karpathy's LLM Wiki technique and the Open Knowledge Format Google has just presented.

We begin by creating the second brain because AI needs context in order to do its work, so the first thing we do in Codex or Claude Code is feed it with our knowledge about robotics, or with the knowledge available in this newsletter, in the humanoid robot database, … and then put it to work.

What comes next is the most exciting part, since there is no limit and we can keep advancing as the development of robotics itself progresses.

If we start from scratch, the first thing will be learning to create skills, for example to evaluate robotics research that we can later apply in our projects. Every day new publications of this kind appear, but it is hard to know whether they can be of real use to us. When the AI knows us, it can tell us whether something new may be useful for our work or isn't worth stopping for.

Once we have created skills, which are a way of standardizing a work process, like a very elaborate prompt that must always be carried out the same way, we can move on to creating automations, which is the way for something already standardized to run recurrently over time. We can use this, for example, to keep up with news about the software or hardware we are using with robots.

From here it gets more exciting, because we can start building things, virtual at first, but later we will be able to move to the physical by having AI agents control a real robot. And at that interface we find simulators, something that until the appearance of agents could be hard to handle because of its technical complexity, but which is now a piece of cake with Agents.

In the course we will keep learning everything new that comes out about Agents in order to apply it to robotics (or to whatever each person wants), because new developments keep coming. For example, we will learn to create software applications for controlling robots and also something that is talked about a lot now: how to generate loops so that agents work autonomously, just what NVIDIA has done with ENPIRE.

The ultimate goal of this new Integrarobot course is for you to be able to use AI Agents to feed robots with training data. There is a lot to learn to get there, which is why I think this is the best time to get down to work.
